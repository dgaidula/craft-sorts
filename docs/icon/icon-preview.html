Craft CMS plugin icon · direction C, in #dc0035

Four bodies, then two, then one

One file, sorts-icon-c-responsive.svg, that rearranges itself by the size it is shown at. Four type bodies in a 2 × 2 case from 40 px up; the rows merge into two tall bodies from 32 to 39 px; below 32 the four merge into one body carrying the pilcrow. The number under each icon is the state its size should select; each is drawn live, so what you see is what the file does.

Switching, at every size

Both rows are the same file: first as an image, then inlined the way Craft inlines it. If the three states were wrong, they would show up here as the wrong count of bodies.

Breakpoints at 40 and 32 px. Below 40 a four-body face is under 8 px across and the ½ closes up, so the rows merge. Below 32 two bodies cannot keep a gutter: WebKit rounds edges outward and shut the 1.75 px gutter at 28 px, so the bodies merge into one. At 128, 64 and 32 every edge lands on a whole pixel by construction; at other sizes the bodies use crisp edges and snap, and the measured table above shows no blended pixels in Chromium.
