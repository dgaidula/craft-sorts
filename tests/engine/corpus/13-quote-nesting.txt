# Which mark a quotation gets: the quote type the author typed (D818), not the nesting depth.
# By default a straight " pair is the locale’s primary pair and a straight ' pair its secondary pair,
# at any depth. quoteNesting=depth (Pro setting “Normalize quotes to house style”) sets every quotation
# by depth instead: primary outermost, secondary inside it, alternating. Each locale and each variant
# is checked for typed double, typed single, and both mixed nestings, under both; expected output is
# written from the locale’s pairs, not copied from the engine.
